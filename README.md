# 🧹 Limpador de Terminal (Shell Script)

Um script em Shell simples e direto para facilitar a navegação, remoção e consulta de arquivos acumulados e lixo no ambiente Linux por meio de um menu interativo no terminal.

O objetivo do projeto é evitar que o usuário precise memorizar comandos longos de remoção (`rm -rf`, `apt clean`, etc.), permitindo limpar o sistema rapidamente escolhendo opções numéricas simples (`1`, `2`, `3`).

========================================
       LIMPEZA DE TERMINAL - MENU       
========================================
1) Limpar Cache de Pacotes (APT)
2) Limpar Cache do Usuário (~/.cache)
3) Esvaziar Lixeira do Sistema
4) Sair
